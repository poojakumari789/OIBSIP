# Personal Portfolio Website

Hi, I'm Pooja Yadav, a B.Tech Computer Science Engineering student who is learning web development and building projects to improve my skills.

This portfolio website introduces me, my skills, my projects, and the ways to contact me.

## About the Project

I created this portfolio as part of my Web Development and Designing tasks. The main goal was to build a personal website with separate pages and a clean, responsive design.

## Pages Included

- **Home:** A short introduction about me.
- **About:** My background and interests.
- **Skills:** Technologies and tools I am learning.
- **Projects:** A collection of my web development projects.
- **Contact:** My contact information and a message form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP for animations

## Features

- Separate pages with easy navigation
- Responsive layout for different screen sizes
- Project cards with images
- Hover effects and animations
- Contact form design
- Consistent colors and typography

## How to Run

1. Download or clone this repository.
2. Open the portfolio folder in VS Code.
3. Open `index.html` in your browser.
4. Use the navigation menu to explore the pages.

## What I Learned

While building this project, I practised creating multiple HTML pages, styling layouts with CSS, making the website responsive, and adding animations using JavaScript and GSAP.
