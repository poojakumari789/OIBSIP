DisasterSafe – Landing Page

This is a simple responsive landing page made as part of my Oasis Infobyte (OIBSIP) Web Development & Designing – Level 1 internship.

About the Project

DisasterSafe is a basic emergency awareness website. The main idea of this landing page is to provide simple information about staying prepared and safe during emergency situations.

I created this project using HTML and CSS and focused on making the page clean, simple, and responsive.

Features

- Sticky navigation bar
- Hero section with a call-to-action button
- About section
- Emergency safety section
- Contact section
- Responsive design for mobile and desktop
- Footer with social/contact links

Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
