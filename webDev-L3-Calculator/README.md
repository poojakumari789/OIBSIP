Calculator App

About the Project

The Calculator App is a simple and responsive web application developed using HTML5, CSS3, and Vanilla JavaScript. It performs basic arithmetic calculations through an easy-to-use button interface.

This project was created as part of my Web Development learning task to practice HTML structure, CSS styling, and JavaScript functionality.

Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.
- Numeric buttons from 0 to 9.
- Decimal number support.
- Clear (C) button to reset the calculator.
- Backspace button to remove the last entered character.
- Equals (=) button to calculate the result.
- Supports operator chaining and follows standard arithmetic precedence.
- Handles division-by-zero errors.
- Responsive layout for mobile and desktop screens.
- Keyboard support for convenient calculations.

Technologies Used

- HTML5 – Structure of the calculator.
- CSS3 – Styling, responsive design, and CSS Grid layout.
- JavaScript (Vanilla) – Calculation logic, event listeners, and error handling.

How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser.
4. Start performing calculations using the calculator buttons.

You can also use the Live Server extension in Visual Studio Code to run the project.
